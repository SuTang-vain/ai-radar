- **蚂蚁百灵开源 Ling-3.1-flash：560B/25B、1M 上下文、MIT 许可** 【已证实】【一手】10 月 15 日 Ant Group 的 inclusionAI 在 Hugging Face 发布 Ling-3.1-flash 权重。模型为 MoE，总参数 560B、激活 25B/token，上下文窗口 1M；官方部署指南显示经 MXFP4 量化后权重从约 534GB 降至 292GB，Hopper 测试配置下可从 8 卡降至 4 卡 serving。同日发布 LingCode（基于开源 coding agent Pi 的 harness），但尚未开源。([Hugging Face](https://huggingface.co/inclusionAI/Ling-3.1-flash))

- **Anthropic 三连发：内部 VCS Scion 披露、Claude Code Review GA、OpenTelemetry 追踪公测** 【已证实】【一手】10 月 14–15 日 Anthropic 连续发布：1) Scion——为 agent-scale 编码重建的内部版本控制系统，7 人 5 个月内从 git 完整迁移，9 月日均合并超 30,000 次（5 月约 2,500 次），但无开源计划；2) Claude Code Review 正式向 Team/Enterprise GA，宣称审查时间从约 20 分钟降至 6–10 分钟；3) Claude Platform 支持向任意 OTLP 端点导出 OpenTelemetry traces，覆盖 Managed Agents、Messages API 与 SDKs。([Anthropic Engineering](https://www.anthropic.com/engineering/redesigning-source-control), [Claude Code Review](https://claude.com/resources/articles/code-review-is-now-generally-available), [Claude OTel](https://claude.com/resources/articles/agent-observability-on-the-claude-platform))
